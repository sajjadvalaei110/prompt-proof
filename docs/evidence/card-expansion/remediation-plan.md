## Remaining limits found while verifying F-02

`placeMissingChildren`'s "already placed" reference for an expanded sibling still uses that sibling's
*collapsed* card size (`cardSizeOf`), not its real (much larger) expanded box — a pre-existing simplification,
not part of this review, and out of scope here. It means a genuinely late child of a container that also holds
an expanded sibling can still be placed too close to that sibling's real box. Reproducing this specific
interaction in the browser check would need a scope-driven late admission nested two levels deep (a class
gaining a new method-holding sibling while its own container is simultaneously mid-expansion), which the
`microservice-java` fixture's whole-system-scope test flow does not exercise; it is recorded here rather than
added as a new invariant.
